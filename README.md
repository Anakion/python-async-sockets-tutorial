# 🔌 Python Async Sockets — Учебный Курс

Практический учебный проект для изучения **сетевого программирования**, **сокетов** и **асинхронности** в Python.

Каждая папка — отдельная тема с подробными примерами, комментариями и объяснениями.

---

## 📚 Структура курса

| № | Папка | Тема | Статус |
|---|-------|------|--------|
| 01 | [`01_sockets_basics/`](./01_sockets_basics/) | Основы сокетов | ✅ Готово |
| 02 | [`02_socket_server_client/`](./02_socket_server_client/) | Сервер и клиент | ✅ Готово |
| 03 | `03_multiple_clients/` | Несколько клиентов | 🔜 Скоро |
| 04 | `04_asyncio_basics/` | Основы asyncio | 🔜 Скоро |
| 05 | `05_async_sockets/` | Async сокеты | 🔜 Скоро |
| 06 | `06_async_server/` | Async сервер | 🔜 Скоро |
| 07 | `07_websockets/` | WebSockets | 🔜 Скоро |
| 08 | `08_real_chat_app/` | Реальное чат-приложение | 🔜 Скоро |

---

## 🛠️ Требования

- Python 3.10+
- Установленные библиотеки: `asyncio` (встроен), `websockets`

```bash
pip install websockets
```

---

## 🚀 Как использовать

Каждая папка содержит:
- `README.md` — теория и объяснения
- `.py` файлы — примеры с подробными комментариями

Читай `README.md` → запускай примеры → экспериментируй!
